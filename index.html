🚀 CI/CD Automation Stages

1

Build & Lint Automated

Code validation, HTML/CSS asset checks, and lightweight Docker container compilation with Nginx on Alpine Linux.

2

SonarQube Quality Gate Strict

Deep static code analysis and security auditing. Pipeline automatically aborts on any Quality Gate breach.

3

Container Health Check Verified

Spins up local test container and runs automated curl probes verifying HTTP 200 response and headers.

4

AWS Production Deploy IaC

Terraform provisions secure AWS EC2/ECR infrastructure with automated user-data container startup and S3 archiving.
